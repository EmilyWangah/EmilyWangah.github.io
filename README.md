# Emily Batubaja — Portfolio v2 (Single Page)

Single `index.html` file — no build tools, no frameworks, no dependencies beyond Google Fonts.
Works immediately on GitHub Pages.

## Deploy to GitHub Pages

1. Create repo named `EmilyWangah.github.io` (or use existing one)
2. Upload `index.html` and `Emily_Batubaja_CV.pdf` to root
3. Settings → Pages → Deploy from branch `main` / root
4. Live at https://EmilyWangah.github.io

## Add a headshot (optional)
The site doesn't use a photo by design (as requested), but if you change your mind:
Add `<img>` in the hero alongside the terminal card.

## To update project Netlify links
Search for `app.netlify.com/teams/emilywangah/projects` and replace each 
with the specific Netlify live URL for that project.
